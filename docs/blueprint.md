# **App Name**: SleepWise AI

## Core Features:

- Fake Authentication: Fake login/registration system using localStorage for first-time access, mimicking authentication flow with login, registration, and password recovery screens.
- Route Protection: Route protection to restrict access to internal content for authenticated users (based on localStorage).
- AI Sleep Reports: AI-Powered Sleep Consultation: Generates personalized sleep reports with tailored advice, using the Gemini API tool from Google Cloud based on user input.
- Report Management: User-friendly interface for viewing reports, which are listed chronologically with options to view within the app and download as a PDF.
- Content Hub: Curated list of complementary resources such as quick sleep tips and links to related videos/articles, plus the 7-day sleep challenge.
- Profile Management: Settings screen enabling users to update profile information, manage their password, access WhatsApp support, and log out.

## Style Guidelines:

- Primary color: Deep purple (#7928CA) to convey sophistication and relaxation.
- Background color: Light lavender (#E6E0EB), almost white, with low saturation to support comfortable reading.
- Accent color: Lilac (#BFA5F7), to provide contrast and highlight key elements.
- Body and headline font: 'Poppins' sans-serif for a modern and readable user interface.
- Simple, clean icons with rounded edges, consistent with the modern design, to improve user experience and navigation.
- Smooth transitions and subtle animations to enhance user experience when navigating between sections, providing a polished feel.
